# Demo Prep

Use these files for pitch, recording, and judge Q&A.

- `demo-script.md`: 2-minute talk track.
- `quick-card.md`: fastest read before presenting.
- `final-runbook.md`: exact verified commands and fallback.
- `final-pitch-card.md`: concise final pitch.
- `codex-criterion.md`: Codex app rubric framing.
- `codex-desktop-shot-list.md`: Codex app recording sequence.
- `judge-qa.md`: short answers for likely questions.
- `scorecard-copy.md`: final verdict wording.
- `recording-checklist.md`: screen recording plan.
- `pitch-snippets.md`: reusable copy.
- `asset-shopping-list.md`: local-only external finisher assets.
- `static-assets/`: optional badge/card SVGs.
