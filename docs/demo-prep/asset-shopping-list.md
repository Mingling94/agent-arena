# Asset Shopping List

Local-only assets for external demo skins.

Do not ship these in the official app package.

## Local Genre Skin A

- arena background
- Codex avatar
- Claude avatar
- objective icon
- assist/helper icon
- victory badge
- defeat/penalty icon
- scoreboard frame

## Local Genre Skin B

- quest background
- Codex avatar
- Claude avatar
- encounter icon
- familiar/helper icon
- quest-complete badge
- XP/reward icon
- parchment-style panel

## Asset Rules

- Keep assets in `../external-skins/*/assets/`.
- Do not commit unlicensed or named-game assets to the official repo.
- Prefer static PNGs.
- Use missing-asset fallback in renderer.
- Avoid music unless licensing is clear.
