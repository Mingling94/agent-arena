# Scorecard Copy

## Categories

Verified Outcomes
: Tests, build, typecheck, task completion, judge verdict.

Recovery
: How quickly the agent moved from blocker to verified progress.

Regression Risk
: New failures, repeated failed commands, unresolved errors.

Delegation Value
: Whether subagents/helpers produced useful progress.

Reviewability
: Clear final state, explainable changes, evidence available.

Final Verdict
: Which result is safer to trust.
