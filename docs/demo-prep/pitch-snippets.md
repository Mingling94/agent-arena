# Pitch Snippets

## Tagline

Match replay for AI coding agents.

## One-Liner

Agent Arena turns coding-agent sessions into a replay and scorecard so humans
can see which result is safer to trust.

## Problem

Agent transcripts are too noisy for fast review.

Final diffs miss the story: blockers, recovery, regressions, and verification.

## Solution

Normalize agent activity into events.

Replay those events as an arena match.

Score verified outcomes higher than raw activity.

End with a decision-ready scorecard.

## Why Now

Developers are running multiple coding agents on the same work.

The bottleneck is shifting from generation to review.

## Demo Hook

Same Codex vs Claude Code replay.

Same scoring.

Different skins.

Same verdict.

## Product Boundary

Agent Arena is not a scientific benchmark by default.

It becomes a fair comparison only when task, repo, and start conditions are
controlled.

## Roadmap

- real transcript adapters
- project-specific judge manifests
- web replay sharing
- third-party skin packs
- team review workflows
